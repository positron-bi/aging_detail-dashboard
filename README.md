# AR Aging Detail Dashboard

داشبورد تک‌صفحه‌ای برای فایل `FactFinnance1.xlsx`.

- فایل داده همراه پروژه است و هنگام اجرا خودکار خوانده می‌شود.
- صفحه یک جدول استاندارد مالی با ستون‌های `FinID`، `عنوان` و `Balance` را تشخیص می‌دهد و فقط حساب‌های دریافتنی تجاری را مبنای تحلیل قرار می‌دهد.
- فیلتر شرکت، حساب، مشتری/کد تفصیل و بازه تاریخ و خروجی اکسلِ گردش فیلترشده دارد.

برای استفادهٔ محلی، یک وب‌سرور ساده اجرا کنید (مثلاً `python -m http.server`) و سپس `index.html` را باز کنید. برای استفادهٔ بدون سرور، فایل اکسل را با دکمهٔ «تعویض فایل» انتخاب کنید.

## محدودیت تحلیلی

دادهٔ ورودی شناسه فاکتور باز و تسویهٔ فاکتور ندارد؛ بنابراین ستون سن، سنِ گردش حساب را بر مبنای ماه سند نمایش می‌دهد و جایگزین گزارش رسمی مانده باز فاکتور نیست.
